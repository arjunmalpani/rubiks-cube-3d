# Rubik's Cube

A 3D Rubik's Cube built with React Three Fiber and Three.js.

Currently in early development. The project starts with a minimal 3D scene and will evolve into an interactive Rubik's Cube with animated turns, move notation, and camera controls.

## Tech Stack

- React + TypeScript
- Three.js + React Three Fiber
- React Three Drei
- Leva
- math
- Tailwind CSS
- Vite

## Getting Started

```bash
npm install
npm run dev
```
